## 视觉方向与首页

安静的“个人手札”：低饱和深绿、浅色正文、薄荷绿强调、少量暖色注记。颜色以原站薄荷绿为依据，不根据未查看的素材推测配色。

首页先展示姓名、原有介绍及 Minecraft / Blophy 身份，再展示两条现有项目的维护/整理状态。精选卡片只展示钻石大陆，提供全部项目入口。Wiki 作为次级明确入口；随后是图库、资源与真实社交主页。

没有增加虚构经历、职业、技能、下载地址、项目成绩或项目时间。移除了封面旋转轨道、光晕和数字指标式首页。

## 项目页面

- 保留 `#/projects`，栏目名称改为“项目与创作”。统一卡片的类型、状态、简介、标签、了解项目、可选 Wiki。
- 新增 `#/projects/:id`，先阅读介绍、角色、记录成果，再进入文档。
- 支持真实提供的 `links`；当前没有凭空添加下载/GitHub 项目地址。
- 没有 Wiki 的项目也能独立存在；个人项目与参与项目使用统一查询。

## Wiki

- `#/wiki` 按项目组织现有六篇文档；桌面左侧目录，手机/平板原生可折叠目录。
- 面包屑、独立浏览器标题与摘要、当前页标记、上一篇/下一篇。
- 翻译说明按原段落分为五节，增加本文目录、注意提示、原文注册行的可复制片段；不改写技术结论。
- “流程梳理”明确标为“整理中”，说明当前属于整理计划。
- 兼容旧 `body` 数组，支持标题、列表、代码、提示与表格块；不引入框架或 Markdown 库。
- 正文桌面 17px、手机 16px，行高 1.9，阅读宽度最多约 68ch；日期/版本只在真实填写时显示。

## Design System / Responsive / Accessibility

- 统一 Primary、Secondary、Background、Surface、Card、Text、Muted、Border、Accent、Hover、Active。
- 统一 Display、H1–H3、Body、Small、Caption、Code；不再使用 7px 的手机辅助文字。
- 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96px 间距，8 / 16px 常规圆角；卡片用边框，浮层才使用轻阴影。
- 小于 960px 折叠导航与 Wiki 目录；小于 640px 使用单列 Hero、项目、社交和图库；完整换行，代码和表格局部滚动。
- 图库沿用原文件，以固定比例容器和 contain 完整显示并预留布局空间；图片文件未重新裁切或转换。
- 语义化页面区域、每页一个 H1、按序标题、无重复 ID、跳至正文。
- 导航 `aria-current`、筛选 `aria-pressed`、明确搜索标签及展开状态。
- 手机菜单关闭时 inert；打开时管理焦点和背景滚动；支持 Tab 循环、Escape 关闭、焦点恢复。
- 页面切换聚焦标题，用独立状态区域播报；搜索支持方向键/Enter；保留图片 alt、画师链接、复制反馈。
- 主要按钮最小高度 44px；图片右键限制缩小到图片区域，不再覆盖画师链接。
- 常用文字与背景/表面/卡片/活动态、主按钮文字的计算对比度均通过 4.5:1 检查；这不是第三方无障碍认证。

## 清理与 Bug 修复

清理旧固定侧栏、封面轨道/光晕、未引用的个人资料样式、卡片未使用参数、重复整份 Wiki 目录的“分页”。搜索索引改为一次生成，纯函数移至 `site-core.js`。

修复：

1. 非法 URL 编码导致 URIError、渲染中止。
2. 未知项目/文章静默显示无关内容。
3. 钻石大陆入口固定指向不存在的 overview；保留旧地址作为兼容别名。
4. 参与项目遗漏于 Wiki 和搜索。
5. 空文档数组导致崩溃。
6. 未知栏目显示首页而栏目文字显示“搜索结果”。
7. 搜索词中的连续斜杠被改写。
8. 资源/图库搜索不能定位具体条目。
9. 固定页面标题、手机菜单键盘行为不完整、筛选状态刷新丢失。
10. 动画偏好刷新重置，减少动态与手动开关不一致。

浏览器检查额外发现 640px 下 Hero 最小宽度造成 33px 横向溢出，已修复并重跑全部布局检查。

3. Google Fonts 网络可用性未验证；测试使用系统字体回退，功能不依赖字体请求成功。
4. 完整游玩流程原本未提供，因此仍为整理中，没有编造攻略。
5. 保留静态 Hash 路由，没有加入每篇文章预渲染 HTML、独立分享卡片或收录保证。
6. 资源/图库精确定位使用数组序号，今后重排会改变这些新增定位地址；原项目/Wiki 的稳定 ID 不受影响。

没有发现阻止本地使用的未解决应用故障。尚未向远端发布或创建提交。
