# 科技风与星星拖尾更新

本次是在个人空间与 Wiki 已有结构上调整视觉风格；项目资料、路由和图片引用保持不变。按后续要求移除了首页“我的项目”旁的重复引言，原个人介绍仍保留。未使用图像生成，未读取图片内容、生成截图或 Base64。

## 修改文件

- `styles.css`：午夜蓝、冰青、浅紫配色；Hero 细网格、几何头像框、等宽注记；4px / 12px 圆角；卡片交互边线；项目与 Wiki 面板的统一顶边；对应的小屏布局和打印样式。
- `app.js`：移除首页项目旁的引言与署名；`styles.css` 同步移除未使用样式，精选项目占满这一行。
- `starfield.js`：默认开启五角星鼠标拖尾、缓慢星空与随机流星；颜色从 CSS Token 读取。背景与拖尾可独立关闭，保留减少动态、后台暂停、触屏过滤和本地偏好。背景关闭且拖尾消退后停止请求动画帧。
- `index.html`：同步浏览器主题色、外观开关与提示文案。
- `README.md`、`docs/phase-2-design.md`：同步当前设计、交互默认值与维护说明。
- `tests/browser-smoke.cjs`、`docs/browser-checks.json`：补充拖尾绘制、空闲停止、触屏过滤、关闭/开启持久化、减少动态验证。测试通过观察绘图调用和动画帧验证，不读取 Canvas 像素。

## 验证

- Node 回归：14 项通过，含正文和常用交互颜色对比度检查。
- Edge 浏览器：15 条路由 × 11 种宽度（320–1440px），165 组布局通过。
- 43 项交互通过，包括无需指针移动的随机流星、项目引言删除与整行布局、星星拖尾、原有导航、搜索、复制、Wiki 目录和 200% 文字缩放。
- 浏览器运行错误：0。阻断图片与外部资源请求，因此这些检查不验证素材视觉表现与网络字体。
- 修复原动画实现会在仅启用鼠标拖尾且鼠标静止时持续请求动画帧的问题。
- 已保存“关闭背景”或“关闭拖尾”的浏览器继续尊重原选择，可在页脚“外观设置”重新开启。
